# Roadmap V3.6 — Selection / Inspector Typography / Semantic Statuses

**Draft-only candidate.** No merge/deployment without independent browser review and explicit site release authorization.

- Disable accidental browser drag-to-select within `.ws-root`, including timeline panning, board dragging, and graph interaction. Native input/textarea/contenteditable selection survives; route links, text, buttons and keyboard focus remain reachable. Scope is engineering workstation only; other site pages are not affected.
- Screen physical PPI is **not reliably available in browser CSS/JavaScript**. DPR and resolution media queries do not equal true screen PPI. Use viewport CSS pixels, rem sizing (honors user zoom), a 306–412px desktop inspector width, and CSS **container queries** to decide metadata row stacking. Prior `9–12px` metadata and body text becomes approximately 12–17px with high-contrast ink and minimum comfortable line-height. Small and large windows have independent geometry; mobile drawer remains a bounded panel.
- Lifecycle stages (`future/planned/development/qualification/review/published`), release confidence (`unassigned/tentative/committed/released`), public event kinds, and project-overview markers receive **distinct evidence-state palettes** instead of inheriting the red theme. Published/released = green, development = amber, qualification = lavender, etc.
- Public board column titles, board delivery-label text and inspector badges all have a locally bundled **static Material Symbols state icon** left of the label, at one em. Inspector development/qualification state icons may subtly breathe as *CSS motion*, which is disabled under `prefers-reduced-motion:reduce`. No external CDN or fetch, no animated replacements of Gantt/inspector handle SVG icons.
- `phase`, `delivery.state` and `publication` remain three independent meanings. A sanitized engineering record is not promoted to committed or released; this change is display-only.
- Tests: mouse drag cannot select timeline/board labels; search remains selectable; published badge green and all states have matching icons; inspector typography/readability; panel container responsive layouts at 1100px and 1920px; desktop/mobile existing regression suite.
